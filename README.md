# SÉRAPHINE — сайт студии красоты

Лендинг + три внутренние страницы для премиальной студии красоты.
Дизайн — «тихая роскошь»: тёплая бумага, крупная антиква Prata, тонкие линии,
арки, зерно плёнки и аккуратная моторика вместо «вау-эффектов ради эффектов».

## Стек

- **React 19 + TypeScript**, сборка **Vite**
- **react-router-dom** — 4 маршрута
- **motion** (Framer Motion) — переходы отзывов, прогресс скролла, прелоадер
- **Lenis** — инерционный smooth-scroll
- **lucide-react** — иконки
- **@fontsource** — Prata + Manrope локально (кириллица, без внешних запросов)
- Чистый CSS с дизайн-токенами, без UI-фреймворков

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc -b && vite build
npm run preview
```

## Страницы

| Маршрут | Что там |
|---|---|
| `/` | Лендинг: hero, манифест, услуги, ритуал визита, мастера, галерея, отзывы, контакты, запись |
| `/services` | Полный прайс с категориями, примечания и FAQ |
| `/masters` | Команда, принципы отбора, цифры |
| `/contacts` | Адрес, часы, соцсети, карта-схема, форма записи |
| `*` | 404 |

## Структура

```
src/
  App.tsx              роутинг + восстановление скролла
  main.tsx             точка входа, шрифты, стили
  styles.css           дизайн-система: токены, компоненты, адаптив
  data.ts              весь контент: услуги, прайс, мастера, отзывы, FAQ
  pages.tsx            страницы
  components/
    chrome.tsx         Header, Footer, Cursor, Preloader, ScrollProgress, Layout
    sections.tsx       секции лендинга + формы
    ui.tsx             Reveal, SplitText, Magnetic, Tilt, Marquee, Photo, Accordion
public/images/         слоты под фотографии (см. IMAGES.md)
```

## Дизайн-токены

| Токен | Значение | Роль |
|---|---|---|
| `--paper` | `#F7F2EA` | основной фон |
| `--paper-2` | `#EFE6D9` | вторичные плоскости |
| `--ink` | `#17130F` | текст, тёмные секции |
| `--bronze` | `#A87E52` | акцент |
| `--muted` | `#857A6E` | подписи |
| `--serif` | Prata | заголовки |
| `--sans` | Manrope | текст, интерфейс |

Типографика на `clamp()` — от 360 до 1440 px без «прыжков» между брейкпоинтами.
Сетка — `max-width: 1360px`, боковые отступы `clamp(20px, 5vw, 72px)`.

## Моторика: что и где

| Эффект | Где | Реализация |
|---|---|---|
| Прелоадер с уходом вверх | первый вход за сессию | motion + `sessionStorage` |
| Появление блока из-под низа | все секции | `IntersectionObserver` + CSS-переход |
| Разбивка текста по словам | манифест | `SplitText` |
| Магнитные кнопки | hero, CTA, ссылки | `Magnetic` (смещение к курсору) |
| 3D-наклон карточек услуг | сетка услуг | `Tilt` (rotateX/Y по позиции мыши) |
| Бесконечная бегущая строка | под hero, прайс | CSS `translateX(-50%)`, пауза по hover |
| Липкие карточки «ритуала» | секция `#ritual` | `position: sticky` с каскадом `top` |
| Кроссфейд отзывов | `#reviews` | `AnimatePresence` |
| Кастомный курсор | весь сайт, только мышь | точка + догоняющее кольцо |
| Частицы в hero | первый экран | Canvas 2D, 54 частицы, DPR-aware |
| Прогресс скролла | верх страницы | `useScroll` + `useSpring` |

Всё уважает `prefers-reduced-motion`: анимации отключаются, контент остаётся.

## Что взято из указанных библиотек

Код писался под этот проект, но паттерны — из конкретных компонентов:

| Источник | Компонент-референс | Наша реализация |
|---|---|---|
| React Bits | Split Text / Blur Text | `SplitText`, `Reveal` |
| React Bits | Marquee | `Marquee` |
| React Bits | Magnet | `Magnetic` |
| Canvas UI | Particle Reveal | `HeroCanvas` (лёгкий Canvas 2D: без WebGL и без html-in-canvas, работает везде) |
| UI Lab (xevrion) | Magnetic button | `Magnetic` |
| UI Lab | Tilt card | `Tilt` |
| UI Lab | Scroll reveal | `Reveal` |
| UI Lab | Accordion | `Accordion` |
| UI Lab | Sticky stack | шаги «ритуала» |
| UI Lab | Marquee | `Marquee` |

Сознательно не тащили сами пакеты: registry-компоненты требуют Tailwind/shadcn
и своего рантайма, а здесь важна целостность стиля и нулевые лишние зависимости.
Если нужно — любой из них можно подключить через `npx shadcn@latest add ...`.

## Доступность и качество

- Семантические `header/nav/main/section/figure/dl`, `aria-expanded` у аккордеона и меню
- Skip-link «К содержанию»
- `:focus-visible` с бронзовым контуром
- Форма: валидация имени, телефона (11 цифр), услуги; ошибки под полем
- Контраст текста на тёмных секциях проверен вручную
- Нет горизонтального скролла на 360–1440 px

## Что это демо, а не продакшн

- Форма записи ничего не отправляет: показывает успешное состояние на клиенте
- Карта — стилизованная схема, не интеграция с картами
- Отзывы и цифры — демонстрационные
- Нет CMS: контент в `src/data.ts`
